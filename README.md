# MotionVideoPipeline

这是一个全新项目的产品需求文档目录，不包含旧项目业务代码。

- [PRD.md](PRD.md)：完整产品需求、架构、UI、视频规范、节点协议和验收标准
- [specs/](specs/)：供 AI 和校验器直接读取的视觉令牌、银河开场、五格进度条、故事板、CanvasWorld、批量任务、固定 GitHub 周榜快照、领域包、音色预缓存、发音计划与质量门禁 JSON 规格
- [项目知识库](项目知识库/)：协作记忆与决策记录

当前约束还包括：所有 Kokoro 音色在音色页打开前完成本地预缓存；核心编排、队列、缓存、数字/发音和导出逻辑按 TDD 实施；每轮修改都必须同步知识库并创建带变更、验证、风险/待办说明的原子提交；GitHub 周榜主源固定为 `https://github.com/trending?since=weekly`。

目标实施位置记录为 `MotionUtil` 的 `f_rebuild` 分支；工程初始化时仍需从新项目边界建立独立代码、依赖和发布目录。

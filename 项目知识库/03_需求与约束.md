# 需求与约束

## 功能需求

- 默认以固定地址 `https://github.com/trending?since=weekly` 的 GitHub 最近一周推荐/Trending 榜单为选题入口，用户配置 `batchCount=N` 后自动批量创建 N 个项目运行；用户不需要逐条输入主题、演讲稿、钩子或资料。
- AI 自动规划并采集仓库主页、README、官方文档、Release、License 和真实案例，整理成事实、案例、应用步骤、原创讲稿 beat 和结论内 hook。
- 单项目主题、演讲稿、钩子、URL 和本地资料仅是可选覆盖输入，不得成为周榜自动批量任务的前置条件。
- Remotion + Three.js 生成连续无边画布动画，不能从静态卡片起步。
- Kokoro 生成中文配音；全部配置音色必须在启动预热阶段提前缓存模型和标准试听 WAV，音色页只读缓存，实际音频时长驱动字幕和动画。
- 英文专名、缩写、命令和 URL 必须经过发音词典或 phoneme hint；阿拉伯整数必须按中文单位读法口播，例如 `12345` 读作“一万两千三百四十五”，显示文本和口播文本分离保存。
- 支持背景音乐、混音、字幕、MP4、证据包和质量报告。
- 节点可插拔、可缓存、可重试、可取消、可从检查点继续。
- WinForms 单例，实时展示节点状态、日志、进度和预计剩余。
- 单个项目失败时自动隔离并继续同批次其他项目；默认模式不设置逐项目人工批准门禁。

## 自动化与领域包约束

- 必须内置可直接运行的 `github-open-source` 领域包，覆盖周榜、GitHub 元数据、官方来源和 Star 字段，不要求人工准备。
- 新领域由 AI 根据自然语言描述自动生成领域包文件、采集器、提示词、钩子、视觉主题和质量规则，并通过 schema、来源覆盖和样片验证。
- 人工仅处理高风险领域合规审核、外部授权、来源白名单和品牌锁定；这些不是普通 GitHub 批量生产的必要步骤。

## 视频约束

- 五个主章节：开场、原理、案例、应用、结论；结论章节最后必须有 hook beat，hook 不得创建独立章节或进度格。
- 竖屏 1080×1920，最长 300 秒，普通语速，全程中文字幕。
- 顶部五格实时进度条，标签固定为 `开场 | 原理 | 案例 | 应用 | 结论`，每格文字水平和垂直居中；元素、字幕和按钮文字不得进入苹果刘海安全区。
- 讲解背景贯穿全片并持续运动，章节过渡自然。
- 开场默认 12 秒：项目名称银河星团缓慢旋转，镜头丝滑拉近聚焦目标项目，再显示总 Star 与固定开场白。

## 技术约束

- Python、Node.js、.NET；Remotion、Three.js、Kokoro 为核心技术。
- 本项目独立仓库、独立 lockfile、独立缓存和独立发布目录，不复用旧代码。
- EXE 固定写入 `artifacts/`，不按版本创建新的 EXE 目录。
- GitHub 周榜主源固定为 `https://github.com/trending?since=weekly`；榜单快照必须保存实际 URL、抓取时间和来源版本，备用源只能在主源失败时按顺序使用。
- 所有配置音色必须在应用启动、首次环境检查或音色版本变化时由 `VoiceCatalogPreloader` 全量预热，缓存 Kokoro 模型/voice embedding 和标准试听 WAV；音色页与试听只能读取本地缓存，禁止点击试听时首次加载、下载或生成。
- 英文专名、缩写、命令和 URL 必须有发音词典引用或 phoneme hint；阿拉伯整数必须转换为中文单位读法，例如 `12345` 读作“一万两千三百四十五”，画面显示文本和口播文本分开保存。
- 批量选择、队列状态机、缓存键与原子写入、数字与发音规范化、音频时间线、进度算法、单例互斥和固定发布目录等核心逻辑必须遵循 TDD；视觉层和 AI 大模型层采用 schema、快照、回放和质量门禁验证。
- 每轮需求、规格或代码改动都必须同步 `项目知识库/05_当前进度.md` 和 `07_历史对话.md`，并创建包含“变更、验证、风险/待办”的单一原子提交。
- AI 实现前必须读取 `specs/visual-tokens.json`、`opening-galaxy.schema.json`、`progress-bar.schema.json`、`storyboard.schema.json`、`canvas-world.schema.json`、`quality-gate-rules.json`、`batch-task.schema.json`、`ranking-snapshot.schema.json`、`domain-package.schema.json`、`voice-cache.schema.json` 和 `pronunciation.schema.json`。

# 项目总览

MotionVideoPipeline 是一个全新的 Windows WinForms 视频内容生产流水线项目。它面向视频自媒体创作者，默认从固定地址 `https://github.com/trending?since=weekly` 的 GitHub 最近一周推荐/Trending 榜单自动发现项目，批量生成带连续画布动画、Kokoro 中文配音、背景音乐、字幕和质量报告的竖屏 MP4。用户只需设置批量数量和运行策略；主题、资料、演讲稿和钩子由 AI 自动完成。

用户指定的实施目标仓库为 `https://github.com/ShiZeHan45/MotionUtil`，分支为 `f_rebuild`；该位置只作为新项目的交付目标记录，不代表复用旧项目代码。

首个领域包是开箱即用的 `github-open-source`，覆盖周榜选题、仓库资料、官方文档、Release、License、真实案例和 Star 字段，不要求人工准备。架构通过领域包扩展到育儿、时事和常识等主题；新领域可由 AI 根据自然语言描述自动生成并验证。核心流程由可插拔节点组成，WinForms 负责编排、配置和观察，Node.js 负责内容与 Remotion，Python 负责 Kokoro，Three.js 负责画布图形和镜头。

本项目不复用旧项目代码、旧依赖目录或旧发布物。最终 EXE 固定放在 `artifacts/`，构建时原子替换，不按每次修改创建新的 EXE 目录。Kokoro 全部配置音色在应用预热阶段提前缓存，核心逻辑按 TDD 实施，每轮改动同步知识库并原子提交。

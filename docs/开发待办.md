## 二、比喻动画：已知局限和后续

- 原理段整段要么全用比喻，要么全退回卡片图，没有按拍混用。动作词汇已经扩到 22 个（只有“列表外”不可画），退回的主要原因将是方向复核不一致或适配度低。
- 方向复核（节点 3 里另一次模型调用，只看原理原文和角色表，回答每一拍的来源和目标，代码与方案比对）能抓“发送方和接收方写反”，但它也是模型判断，不是形式证明。你看到仍有画反的，把该项目的 `.comprehension.json` 和比喻方案（讲稿缓存里的 `metaphor` 字段）发我。
- 每一拍只有一个画面步骤。像“助手经接口交给服务”这样一拍里有两跳的，只能画一跳。若这类拍太多，考虑允许一拍多个步骤。
- 对照依据：只检查“对应对象”能否在讲稿里找到（至少 70%），没有逐拍核对比喻说明是否新增了原文没有的步骤。
- 包裹颜色目前只有三种（黄、青、珊瑚），超过三种信息的链路要复用颜色。
